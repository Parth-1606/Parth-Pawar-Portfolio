**Live:** https://parth-pawar-portfolio.vercel.app/

## What's inside

- **Hero** — staggered entrance, rotating "currently building" line, count-up stats
- **Selected work** — Validify (AI SaaS validator), Golden Hour (emergency triage &
  hospital routing), Assessment Recommendation Agent (conversational RAG)

- **Toolkit** — languages, AI/ML, frontend, backend, databases, infra
- **GitHub, live** — contribution heatmap + repos/stars/followers/following,

- **LeetCode, live** — submission heatmap for the current year, Easy/Medium/Hard
  split, streak, rank, recent submissions
- **Contact** — details + working message form (opens the visitor's mail app)
- Motion throughout: scroll progress bar, reveal-on-scroll, 3D tilt project
  cards with cursor spotlight + shine sweep, heatmap cell pop-in, marquee
  ticker, back-to-top button

## Stack

- Single `index.html` — **no build step**, just open it
- Tailwind CSS via CDN, Fraunces + Inter + JetBrains Mono
- Vanilla JS + free public APIs (GitHub REST, LeetCode mirrors) — no API keys

## Run locally

Open `index.html` in any browser, or serve the folder:

```bash
npx serve .
```

## Point it at different accounts

Change the default values of `#ghInput` (GitHub username) and `#lcInput`
(LeetCode username) in `index.html`. Both sections also accept any username at
runtime via the Load box — no code changes needed.

## Deploy

Any static host works (Vercel, Netlify, GitHub Pages) — it's one HTML file.
